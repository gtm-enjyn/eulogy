# Ten implementation decisions

| # | Context | Choice | Alternative considered and rejected | Reason and evidence |
|---|---|---|---|---|
| 1 | Every relative needs a viewpoint, and the film has six chapters. | One ensemble request per chapter with separate state per character. | A separate model request for each character's every line. | A six-character life needs six base requests. Each reply includes all relative states so continuity can be checked at one boundary. [Chapter loop](../packages/sim/src/simulate.ts) |
| 2 | A structurally valid reply can still introduce an unknown actor or an impossible score jump. | Zod parsing, cast checks, one corrected request, then a seeded fallback with chapter provenance. | Accepting the response after JSON parsing or retrying indefinitely. | A malformed chapter has a bounded cost and a visible origin when replayed. [Contract tests](../packages/sim/src/chapter-contract.test.ts) |
| 3 | A persuasive model can write a farewell for a person who has withdrawn. | Compute `speaks` from the last score with an inclusive threshold of 55. Preserve silent text. | Asking the model to decide eligibility itself. | The renderer, database and tests agree at the boundary, and the silent relative keeps a voice in the private feed. [Shared run validation](../packages/shared/src/schemas.ts) |
| 4 | Runs need enough variability to compare without overwriting one another. | Seeded per-life PRNGs, sequential chapters, ten workers and disjoint 50-seed batches. | Global random state shared across workers. | A reordered worker cannot consume another life’s randomness. The 1,000-life file has a reproducible digest. [Scale proof](assets/ensemble-1000.json) |
| 5 | Free-text first decisions fragment the analytical groups. | Give the protagonist three opening actions and allow a free-text reason. | Grouping semantically similar prose after the event with another model. | Identical opening actions get comparable denominators. Their reasons retain an individual character's voice. [Action vocabulary](../packages/sim/src/chapter.ts) |
| 6 | Several relatives can have the same role, and some profiles contain no child. | Fold role flags at run grain and keep a missing role null. | Counting funeral rows directly as independent lives. | Family size cannot overrepresent a run or silently turn missing children into silent children. [Outcome staging](../bruin/eulogy/assets/stg_outcomes.sql) |
| 7 | The opening decision can look striking when observed in very few lives. | Require three lives in both cohorts, publish both counts and express the difference in percentage points. | Ranking raw percentage differences for every action. | The reader can inspect the sample behind each comparison. [Decision query and denominators](assets/decision-impact.txt) |
| 8 | The film and its analytics need to survive service and network loss. | Commit an attributed JSONL screening, query export, room transcript, avatars and featured audio. | Generating every asset when the visitor first opens the site. | A fresh clone can play the service, and CI rebuilds the analytics from the same inputs. [Workflow](../.github/workflows/ci.yml) |
| 9 | Sponsor access varies between a deployed account and a keyless clone. | Share payload builders between authenticated requests and dry-run receipts, and label their mode. | Manufacturing successful provider responses for the demo. | A reviewer can compare the wire body with the provider contract and see which result was actually observed. [Provider contracts](SPONSOR-CONTRACTS.md) |
| 10 | Playback must remain intelligible when rendering or audio is interrupted. | Drive captions, ledger and navigation from the run outside the WebGL canvas. Pose a shared skeleton and interpolate camera and speaker positions. | Coupling the whole service to an externally hosted rig, motion clip or speech callback. | The projection can fail while the visitor continues with the service. A Chrome run with WebGL disabled exercises that path. [Browser results](assets/browser-check.json) |
